## 📋 Детальный чеклист по дням

### 📅 День 1: Подготовка (8-10 часов)

#### Утро (09:00-13:00)
```
✅ 09:00-10:00  Создание app icon (1024×1024)
                Инструмент: https://icon.kitchen/
                
✅ 10:00-11:00  Создание adaptive icon для Android
                Центральная зона: 768×768px
                
✅ 11:00-12:00  Splash screen и feature graphic
                Feature: 1024×500px для Play Market
                
✅ 12:00-13:00  Установка и настройка EAS CLI
                npm install -g eas-cli
                eas login
                eas build:configure
```

#### Обед (13:00-14:00)
```
🍕 Перерыв
```

#### День (14:00-18:00)
```
✅ 14:00-15:00  Создание скриншотов
                - Android: 1080×1920 (минимум 2)
                - iOS: 1242×2688 (минимум 3)
                Используйте эмуляторы
                
✅ 15:00-16:00  Написание описаний
                - Краткое (80 символов)
                - Полное (400-4000 символов)
                - Ключевые слова
                
✅ 16:00-17:00  Политика конфиденциальности
                Опубликовать на GitHub Pages
                или использовать готовый PRIVACY_POLICY.md
                
✅ 17:00-18:00  Тестовая сборка
                eas build --platform android --profile preview
                Проверить на реальном устройстве
```

---

### 📅 День 2: Регистрация и публикация (8-10 часов)

#### Утро (09:00-13:00)
```
✅ 09:00-10:00  Регистрация в Google Play Console
                - Оплата $25
                - Создание приложения
                - Согласие с политиками
                
✅ 10:00-11:30  Заполнение Play Console
                - Store listing (описание, скриншоты)
                - Content rating (анкета)
                - Pricing & distribution
                - App content (privacy policy URL)
                
✅ 11:30-12:00  Production сборка Android
                eas build --platform android --profile production
                Скачать AAB после завершения
                
✅ 12:00-13:00  Загрузка в Internal Testing
                Play Console → Internal testing → Create release
                Загрузить AAB
```

#### Обед (13:00-14:00)
```
🍕 Перерыв
```

#### День (14:00-18:00)
```
✅ 14:00-15:00  Регистрация Apple Developer
                - Оплата $99/год
                - Подтверждение личности
                - Может занять несколько дней!
                
✅ 15:00-16:00  Создание App ID и App Store Connect
                - Developer Portal → Identifiers
                - Bundle ID: com.startuphub.app
                - App Store Connect → My Apps → New App
                
✅ 16:00-17:00  Заполнение App Store Connect
                - Метаданные (название, описание)
                - Скриншоты для всех размеров
                - Privacy Policy URL
                - App Review Information
                
✅ 17:00-18:00  Production сборка iOS
                eas build --platform ios --profile production
                Автоматически загрузится в TestFlight
                Выбрать билд в App Store Connect
```

```
   - Настроить analytics и crash reporting
```

## 💡 Советы для быстрой публикации

### ⚡ Параллелизация задач
```
Можно делать одновременно:
├─ Создание графики (дизайнер)
├─ Написание текстов (контент-менеджер)
├─ Настройка EAS (разработчик)
└─ Регистрация в консолях (владелец аккаунта)

Нельзя делать одновременно:
├─ Сборка (только одна активная на Free плане)
└─ Загрузка билдов (нужен готовый файл)
```

### 🎯 Критический путь (минимум времени)
```
1. Иконки (обязательно)           → 1 час
2. Скриншоты (минимум)            → 1 час
3. Описания (шаблоны)             → 30 минут
4. EAS setup + build              → 1 час
5. Регистрация Play Console       → 30 минут
6. Загрузка Android               → 30 минут
                                    ─────────
                            Итого:   4.5 часа

iOS можно сделать позже (требует ожидания Apple Developer approval)
```
